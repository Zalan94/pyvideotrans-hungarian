# 🇭🇺 pyVideoTrans Magyar Nyelvi Csomag

Magyar nyelvű fordítás a [pyVideoTrans](https://github.com/jianchang512/pyvideotrans) videó fordító/szinkronizáló szoftverhez.

## Telepítés

1. Másold a `hu.json` fájlt a pyVideoTrans `videotrans/language/` mappájába
2. Nyisd meg a `videotrans/cfg.json` fájlt és írd át: `"lang": "hu"`
3. Indítsd újra a programot

## Fordítás állapota

- **755 / 937** elem lefordítva magyarra (80%+)
- Menük, gombok, hibaüzenetek, állapotjelzők, beállítások mind magyarul
- Technikai/API nevek (ElevenLabs, GPT-SoVITS, stb.) angolul maradtak

## Kompatibilitás

- pyVideoTrans v3.95
- Windows 10/11
